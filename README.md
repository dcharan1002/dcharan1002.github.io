# Charan Kumar Domalapati · Portfolio

Personal portfolio website. Everything (styles, scripts and images) is inside `index.html`, so there is nothing to build or install.

## Publish with GitHub Pages

1. Create a new public repository on GitHub, for example `dcharan1002.github.io` (this name gives you the address `https://dcharan1002.github.io`).
2. Upload `index.html` and this `README.md` to the repository (Add file → Upload files → Commit changes).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose the `main` branch and the `/ (root)` folder, then click **Save**.
5. After a minute or two the site is live at `https://dcharan1002.github.io` (or `https://dcharan1002.github.io/<repo-name>` if you used a different repository name).

## Updating the site

Edit `index.html` on GitHub (pencil icon) or upload a new version. GitHub Pages republishes automatically after each commit.
